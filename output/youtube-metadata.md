A Docker Container Is NOT a Tiny VM (It's Just a Process) #shorts

## Description
A Docker container is not a tiny virtual machine. It's just a Linux process with boundaries.

In 60 seconds:
• Why a VM needs a full guest OS and its own kernel
• How containers share the host's Linux kernel
• Namespaces: what the process can SEE (PID 1, its own network and hostname)
• cgroups: what the process can USE (CPU and memory limits, OOM kill)
• Layered filesystem: read-only image layers + one writable layer
• Proof: run `ps` on the host and your container is right there

That's why containers start in a fraction of a second and one server can run hundreds of them.
